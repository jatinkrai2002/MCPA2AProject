ConversationalUI

    Text input for free-form user entry.

    Radio button for multiple-choice selection.

    File upload supporting images (png, jpg, jpeg) and text files (txt).

    Three buttons: Submit (process inputs), Cancel (clear/reset), Close (stop app).

    Outputs displayed on the same page: echoes text, shows selected option, displays uploaded image or text file content.

You can run this with:
streamlit run app.py
or
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8080
This gives you a conversational-style UI with structured inputs and outputs.
